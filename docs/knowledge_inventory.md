## 🗺️ 推荐学习路线

```
第 1 周：基础工具
  ├── Linux 命令行（进程、权限、日志）
  ├── Git（diff, log, branch, reset）
  └── 理解你的 bashrc/setup 在干什么

第 2 周：固件层深挖
  ├── 中断 + volatile 彻底搞懂（为什么编码器计数用 volatile）
  ├── PWM 原理（占空比到底是什么）
  └── 串口通信原理（波特率、TTL 电平）

第 3 周：机器人学核心
  ├── 差速运动学公式推导（从纸上画图到代码）
  ├── 开环 vs 闭环（你现在是开环，区别在哪）
  └── 里程计原理 + 为什么一定会漂移

第 4 周：ROS2 深入
  ├── Node/Topic/Message 三大概念
  ├── TF 树到底是什么
  └── 几个 ros2 调试命令

第 5 周：PID 实战
  ├── P 项：比例控制（差多少补多少）
  ├── I 项：积分（累积误差修正）
  ├── D 项：微分（预测趋势，防止过冲）
  └── 在你的 ESP32 固件里实现速度环 PID

之后按需深入：
  ├── 电池到了 → 理解电池放电曲线 + 电压补偿
  ├── 想用 IMU → 学四元数/欧拉角/互补滤波
  ├── 想做 SLAM → 学激光雷达 + 粒子滤波
  └── 想做路径规划 → 学 A* / DWA
```

## ⚠️ 关键提醒

1. **不需要按顺序全部学完再动手。** 拿到哪个知识点就用哪个，用的时候再深挖。

2. **标 ⭐ 的东西加起来也就 30 来个**，按一天搞明白 2-3 个的节奏，两周能过完。

3. **你现在缺的不是知识，是知识之间的连线。** 你会写 `attachInterrupt` 但可能讲不清"CPU 收到中断信号后硬件层面发生了什么"——现阶段不需要讲到那个深度。先知道"中断来时 CPU 暂停主循环、跳去执行 ISR、执行完回来"，够了。

4. **PID 是下一个分水岭。** 把开环变成闭环，是"能跑"和"跑得准"的区别。这在你的 ESP32 固件里就是改 `set_motor()` 函数的事。
